# Research Handoff Notes for Codex

## Why this exists

The original PCT book and original NowMind code were discussed and used in earlier ChatGPT work, but their raw files are not currently recoverable from the accessible file store.

This folder therefore distinguishes:

- **ORIGINAL / RECOVERED** sources;
- **RECONSTRUCTED** context;
- **MISSING ORIGINALS**.

Never blur those categories.

## Use during G1

G1 may proceed using the root project specifications.

Use the reconstructed files to understand the wider research direction, but do not implement later-stage features from them.

## When originals are added

If Jonathan later provides the original book/code:

1. place them in the paths listed in `reference/SOURCE_INDEX.md`;
2. inspect them;
3. update the source index;
4. record any conflict with the reconstructed summary;
5. do not silently rewrite G1 architecture;
6. raise conceptual conflicts in `docs/OPEN_QUESTIONS.md`.

## Research credibility rule

When preparing public/research material, distinguish:
- what PCT proposes philosophically;
- what NowMind implements computationally;
- what experiments actually demonstrate;
- what remains speculation.

This distinction is especially important for consciousness, identity, quantum interpretations, and claims about model reasoning.
