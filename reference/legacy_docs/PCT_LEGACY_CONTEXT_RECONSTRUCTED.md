# PCT Legacy Context — Reconstructed from Prior Work

**Status:** Reconstructed contextual document.  
**Not a substitute for the original PCT book.**

This document captures PCT ideas repeatedly established in prior work so Codex has broader conceptual context while the original book is unavailable.

## 1. Present-bound consciousness

A core PCT principle is that consciousness is present-bound.

A previously used compact formulation was:

`C(t_now) = f(S)`

where the conscious state at the current instant depends on the current substrate/state, rather than consciousness itself residing in memory or prediction.

Memory and prediction can influence what appears now, but they are not themselves separate temporal locations of consciousness.

## 2. The Waterfall perspective

PCT rejects the intuitive picture of consciousness as one continuous object moving smoothly from past to future.

The Waterfall metaphor treats apparently continuous experience as successive present configurations.

Important computational implication:

- there may be causal continuity in the physical/system process;
- there may be informational continuity;
- but the active conscious/computational representation is always the current Now.

This does not mean the world or consequences disappear between moments.

## 3. Memory

Prior NowMind/PCT work repeatedly distinguished memory from the current conscious state.

Memory should be modeled as:

`event -> trace -> storage -> retrieval -> reconstruction in the present`

rather than:

`past consciousness -> replayed directly as present consciousness`

Key ideas:
- memory is a tool;
- retrieval is reconstruction;
- reconstruction can be fuzzy, partial, cue-triggered, or altered by present context;
- exact replay of an earlier conscious Now should not be assumed.

## 4. Continuity

PCT treats the felt continuity of self and experience as constructed/stiched across present moments.

This does not mean continuity is useless or unreal in every sense.

The continuity model can remain causally and practically important while not being identical to a literally persisting conscious object.

## 5. Identity

Prior discussion explored a "vanishing" or moment-bound self while still preserving responsibility and causal consequences.

For NowMind, the safest computational interpretation is:

- identity at cycle `t` is constructed in the present;
- autobiographical memory contributes but is not identical to identity;
- relatively stable constraints/anchors can contribute to continuity;
- there should be no single mutable database object casually equated with "the self."

Later Geometric Now work introduced the useful idea of **identity invariants**. This should be interpreted as stable relational/ethical/structural constraints across Nows, not as proof of an ontologically permanent self-object.

## 6. Dreams

Dreams have been an important PCT example because dream experience can present an apparently established history that is generated inside the current dream state.

Prior NowMind design required dreaming to use only already experienced/internal material, with no live external information.

Three broad dream modes had been accepted:
- internal simulation;
- memory recombination;
- random present-like processing.

Dreaming belongs to a later NowMind generation, not G1.

## 7. Responsibility and consequences

The PCT perspective does not imply that past actions have no consequences.

A previous explanatory distinction was:

- the past conscious moment is no longer the current moment;
- the effects of prior actions can persist in the world;
- social, ethical and legal responsibility can therefore persist.

This distinction matters for any later ethical architecture.

## 8. Prediction and future

A possible future should be represented as a hypothesis that exists **now**.

In software terms:

`HYPOTHETICAL_FUTURE`

must be epistemically distinct from:

`OBSERVED_NOW`

The system should never mistake prediction for perception.

## 9. Quantum discussion

PCT has explored quantum aspects/analogies.

For the engineering project, keep three categories separate:

1. quantum metaphor or analogy;
2. mathematical formalism inspired by quantum probability/possibility;
3. an empirical claim that physical quantum processes cause consciousness.

The Geometric Now project currently makes no claim of category 3.

No quantum mechanism is required for G1.
