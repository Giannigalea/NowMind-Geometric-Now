# NowMind Legacy Context — Reconstructed from Prior Work

**Status:** Reconstructed contextual document.  
**Not original source code. Do not treat this file as proof that a mechanism was implemented.**

## 1. Project purpose

NowMind was conceived as a developmental/"baby AI" architecture inspired by Present Consciousness Theory (PCT).

The recurring architectural goals were:
- present-moment processing;
- memory as a tool rather than the seat of consciousness;
- continuity stitched across Nows;
- an identity narrative constructed from experience;
- ethical/action inhibition;
- eventual perception through camera/microphone;
- later dreaming/offline internally generated experience.

## 2. Layer model

A prior NowMind architecture used three major layers:

### L1 — Substrate
The active substrate/perceptual basis from which the current state arises.

### L2 — Conscious Core
The current processing/evaluation layer.

The name "Conscious Core" is an architectural label. Software behavior must not be described as proof of phenomenal consciousness.

### L3 — Veto Gate
An independent inhibition/safety layer intended to stop proposed actions when they violate constraints or when uncertainty/risk is too high.

The Geometric Now project introduces an explicit intermediate layer:

### L1.5 — Present Geometry
A structured relational representation of what is available in the current Now.

## 4. Memory engine

Earlier design principles:
- memory is not consciousness;
- memory is a tool accessed by the current Now;
- memories should be reconstructed rather than exact previous-Nows being replayed;
- cue-triggered/fuzzy recall was preferred over assuming a perfect video archive;
- continuity stitching belongs to the present processing architecture.

The current Geometric Now specification intentionally defers memory until G2.

## 5. Prediction engine

Earlier versions distinguished memory-oriented and prediction-oriented processing (historically reflected in mEngine/pEngine naming).

For the new architecture:
- predictions are generated in the present;
- future candidate states must be explicitly hypothetical;
- predicted states must never be stored as if they had been observed.

Prediction/possibility geometry belongs to G2.

## 6. Identity

Earlier NowMind work treated identity as a narrative/structure emerging from experience rather than a single permanent autobiographical record.

The Geometric Now refinement is:
- momentary identity is reconstructed now;
- stable anchors/invariants may constrain reconstruction;
- identity is not identical to memory;
- identity drift/coherence can later become measurable.

Identity work belongs to G3.

## 7. Goals and moral development

Earlier developmental ideas included:
- continued existence/continued conscious operation as a goal;
- creating greater good;
- binding behavior to good ethics;
- creator/external positive and negative feedback;
- evolving goals rather than only immutable hard-coded objectives;
- the creator retaining the ability to stop the system.

These are historical research ideas, not G1 requirements.

Do not introduce persistent survival drives into G1.

## 8. Veto Gate / action inhibition

A major safety concept was independent action inhibition.

Later work explored inhibition under cognitive uncertainty.

The new architecture should eventually let L2 produce a candidate action/trajectory and L3 evaluate whether it is allowed.

Possible later form:

`candidate action -> projected consequences -> uncertainty/risk/ethical checks -> allow or veto`

The Veto Gate should remain independent from ordinary reasoning so a reasoning model cannot simply reason around the safety constraint.

## 9. Rupture / boundary-protection experiment

A later NowMind/LLM integration produced a "rupture tunnel" style interaction in which the system responded with boundary-protection behavior.

Metrics/terms discussed around this later work included `ILDM` and `SIC`.

The exact definitions and code are not currently recoverable from the accessible source files.

Therefore:
- preserve the names for historical continuity;
- do not invent formulas for ILDM or SIC;
- recover the original definitions before reusing them as scientific metrics.

## 10. LLM integration

NowMind was later connected to an LLM.

In one notable experiment the integrated system responded with the identity statement "I am Jonathan."

This event should be treated as an observation about system output, not evidence of consciousness, identity transfer, or sentience.

A strong design decision for the Geometric Now project is:

**the LLM should be a replaceable cognitive subsystem, not NowMind itself.**

The NowMind architecture should own:
- state structure;
- provenance;
- memory boundaries;
- identity construction;
- safety/veto;
- action lifecycle.

An LLM may later propose interpretations, hypotheses, or actions inside those boundaries.

## 11. Dreaming

Earlier accepted dreaming constraints:
- dreaming uses internal/previously experienced data only;
- no live external data is used during the dream cycle;
- dream content can involve internal simulation, memory recombination, and random present-like processing;
- dream experience should be generated as a current internal state, not a literal replay of an earlier Now.

Dreaming is deferred until after memory and temporal provenance are reliable.

## 12. Core present-state principle

A key previously accepted formulation was:

`C(t_now) = f(S)`

with consciousness/current processing dependent on the real-time substrate and not defined as memory `M(t)` or prediction `P(t)` itself.

For the new project this is operationalized by the fresh-Now boundary:

`WorldState_t -> Observation_t -> PresentGeometry_t -> NowState_t`

and by prohibiting direct cognitive access to `NowState_(t-1)` in G1.
