# NowMind Reference Folder

This folder is designed to be copied directly into the root of the **NowMind Geometric Now** project created from the Codex starter pack.

## Important status

This reference set contains:

- one **original/recovered PCT source** available in the ChatGPT file library:
  - `pct/PCT_Waterfall_of_Now_Transcript.txt`
- two **reconstructed context documents** prepared from prior PCT/NowMind work:
  - `legacy_docs/PCT_LEGACY_CONTEXT_RECONSTRUCTED.md`
  - `legacy_docs/NOWMIND_LEGACY_CONTEXT_RECONSTRUCTED.md`
- a source index describing authority and provenance;
- placeholders documenting original files that were discussed previously but whose bytes are not currently accessible in the file library.

## What is still missing

The following original source files were referenced in prior work but could not be recovered from the currently accessible file store:

1. the latest full PCT book, previously named similar to:
   `Present_Consciousness_Theory_Book_Print_Ready.pdf`
2. the original/latest NowMind source repository or ZIP;
3. any separate original AICU / GLIM-N+ / benchmark files, if these existed as standalone files.

Do **not** let Codex infer that these missing originals are present.

## Can G1 start without them?

Yes.

The G1 computational architecture is already governed by:
- `AGENTS.md`
- `docs/PCT_COMPUTATIONAL_RULES.md`
- `docs/GEOMETRIC_NOW_G1_SPEC.md`
- `docs/G1_ACCEPTANCE_TESTS.md`

The reconstructed legacy context is sufficient to keep Codex aligned with the broader design while G1 is built.

Before serious G2/G3 work, the original PCT book and latest legacy NowMind code should be added if available.
