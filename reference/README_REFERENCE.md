# NowMind Reference Folder

This folder contains supporting source and legacy-context material for the
**NowMind Geometric Now** research package.

## Important status

This reference set contains:

- one **original/recovered PCT source** intentionally distributed here:
  - `pct/PCT_Waterfall_of_Now_Transcript.txt`
- two **reconstructed context documents** prepared from prior PCT/NowMind work:
  - `legacy_docs/PCT_LEGACY_CONTEXT_RECONSTRUCTED.md`
  - `legacy_docs/NOWMIND_LEGACY_CONTEXT_RECONSTRUCTED.md`
- a source index describing authority and provenance;
- provenance notes documenting original files discussed historically but not
  distributed in this repository.

## What is still missing

The following original source files were referenced in prior work but could not be recovered from the currently accessible file store:

1. the separately published full PCT book;
2. the original/latest legacy NowMind source repository or ZIP;
3. any separate original AICU / GLIM-N+ / benchmark files, if these existed as
   standalone files.

Do **not** infer that these missing originals are present.

## Role in the completed package

G1 was implemented and validated without these missing originals. The Full-G
package includes later stages through G2.3.4.

The G1 computational architecture is documented by:
- `docs/PCT_COMPUTATIONAL_RULES.md`
- `docs/GEOMETRIC_NOW_G1_SPEC.md`
- `docs/G1_ACCEPTANCE_TESTS.md`

The reconstructed legacy context preserves the broader design history; it is
not a dependency for the implemented stages.

For future private review or later-stage work, the separately published PCT book
and latest legacy NowMind code may be consulted if available, but the full book
is not distributed in this public repository.

## Authority

For implemented G1 behavior, consult the computational rules and specifications
under `docs/`.

Reconstructed files are **context**, not authoritative replacements for originals.
