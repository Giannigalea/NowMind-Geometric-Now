# G2.1 Limitations

- The world is a synthetic deterministic grid, not real perception.
- Planning is symbolic A*, not learned policy search.
- Memory assumptions are compact occupancy propositions, not rich episodic
  memory.
- Future hypotheses are typed possibilities and visual overlays; they are not
  probabilistic world simulators.
- The benchmark is synthetic and should not be presented as a state-of-the-art
  AI planning comparison.
- Physical constraint rejection is not an L3 ethical Veto Gate.
- The browser demo is an inspector for architecture behavior, not a cognitive
  user interface.
- No identity, dreaming, LLM integration, cloud dependency, or quantum mechanism
  is implemented in G2.1.
