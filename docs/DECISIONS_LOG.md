# Decisions Log

Keep this file append-only.

## D-001 — Separate WorldState from NowState
**Status:** Accepted for G1.

Reason:
The world must be allowed to persist while each cognitive Now is reconstructed fresh. Equating persistent environment state with persistent cognitive state would defeat the core PCT experiment.

## D-002 — No LLM in G1
**Status:** Accepted.

Reason:
We need to know whether the architectural representation works independently of model scale and prompt behavior.

## D-003 — Deterministic relational geometry first
**Status:** Accepted.

Reason:
Transparent rules provide falsifiable tests and explanation chains.

## D-004 — Memory deferred to G2
**Status:** Accepted.

Reason:
G1 must prove a clean current-state boundary before historical information is allowed back into the system.

## D-005 — Identity deferred to G3
**Status:** Accepted.

Reason:
Identity is conceptually important but would obscure the foundational G1 experiment.

## D-006 — Identity anchors are not a fixed self object
**Status:** Accepted as roadmap constraint.

Reason:
Earlier PCT/NowMind design treats identity/continuity as reconstructed in the present. Stable constraints may participate without becoming the entirety of the self.

## D-007 — External history recorder allowed
**Status:** Accepted.

Reason:
Experiments need exact historical ground truth. It must remain outside the runtime cognitive path.

## D-008 — Quantum mechanism excluded from G1
**Status:** Accepted.

Reason:
No defined falsifiable quantum mechanism is required for Present Geometry. Keep speculative/metaphysical claims separate from engineering.

### D-011 - Conservative deterministic inference confidence
**Date:** 2026-08-22
**Status:** Accepted

**Decision:**
Use `confidence(inference) = min(confidence(premises))` for inverse, symmetric,
and transitive inference.

**Reason:**
This satisfies G1 confidence requirements without inventing probabilistic
semantics.

**Consequences:**
Inferred confidence never exceeds the least-confident premise.

### D-026 - Memory is trace-to-reconstruction, not old-Now replay
**Date:** 2026-08-23
**Status:** Accepted

**Decision:**
Represent G2 memory as immutable `MemoryTrace` records stored in `MemoryStore`
and reconstructed into current `MemoryReconstruction` objects through explicit
retrieval cues.

**Reason:**
PCT requires remembered content to appear as a present reconstruction, not as a
direct cognitive path from an old NowState.

**Consequences:**
Memory traces store compact propositions and provenance. They reject raw
`NowState`/`TemporalNowState` objects, and deleting actual MemoryStore traces
changes later reconstructions while deleting researcher history does not.

### D-027 - Future hypotheses remain present hypothetical content
**Date:** 2026-08-23
**Status:** Accepted

**Decision:**
Represent future possibilities as immutable `FutureHypothesis` records with
`HYPOTHETICAL_FUTURE` provenance.

**Reason:**
G2 tests temporal source separation, not full possibility geometry. A future
hypothesis must be inspectable in the current Now without becoming observation.

**Consequences:**
Future hypotheses cannot answer NOW queries, cannot be encoded as observed
memory, and are not mutated into observations. Later confirmation creates a new
`OBSERVED_NOW` fact.

### D-030 - Hypothetical geometry remains HYPOTHETICAL_FUTURE
**Date:** 2026-08-23

**Reason:**

**Consequences:**

### D-031 - Planner uses transparent A* and explicit memory assumptions
**Date:** 2026-08-23
**Status:** Accepted

**Decision:**
Use deterministic A* with Manhattan distance, four-directional movement,
deterministic tie-breaking, and explicit conditional assumptions for
memory-supported unknown cells.

**Reason:**
The planner must be inspectable and source-safe. Memory can support a conditional
route but must not be silently relabeled as current free occupancy.

**Consequences:**
Observed occupied cells always block. Observed free cells override stale memory.
Unknown cells require `RECONSTRUCTED_MEMORY` assumptions and mark plans
conditional. Future hypotheses are rendered and benchmarked as possibilities,
not current targets.

### D-033 - G2.2 partial observation is runtime input boundary
**Date:** 2026-08-23
**Status:** Accepted

**Decision:**
Add `nowmind.epistemic` as an additive runtime layer that builds
`EpistemicGeometry` from bounded current observation rather than full spatial
world truth.

**Reason:**
G2.2 tests whether planning can remain source-safe when the present is
incomplete. Runtime planners must distinguish observed free, observed blocked,
and unknown cells.

**Consequences:**
Only the evaluator and oracle may inspect complete ground truth. Unknown cells
have no `OBSERVED_NOW` provenance, and memory/future candidates attached to
unknown cells do not change their observed occupancy.

### D-034 - SCAN is information gathering, not world mutation
**Date:** 2026-08-23
**Status:** Accepted

**Decision:**
Implement `SCAN` as an explicit epistemic action with cost. It increases the

**Reason:**

**Consequences:**

### D-040 - Falsified memory changes current planning status, not history
**Date:** 2026-08-23
**Status:** Accepted

**Decision:**
When current observation falsifies a remembered target location or remembered
free cell, mark the current planning assumption as disconfirmed or invalidated
while preserving the historical memory record.

**Reason:**
PCT treats memory as reconstructed present content, not as a mutable container
that becomes retroactively true or false. The old trace can remain historically
real while the current assumption is no longer usable.

**Consequences:**
The recovery layer records disconfirmed target poses, invalidated poses,
reacquisition attempts, and reacquisition successes. Planning excludes those
current assumptions without deleting memory.

### D-041 - Agent-occupied fog cell is current observation
**Date:** 2026-08-23
**Status:** Accepted

**Decision:**
Treat the agent's own occupied cell as currently observable even if that cell
was previously marked hidden/fogged.

**Reason:**
If the agent reaches a remembered hidden target location and the target is not
there, that absence is current evidence. Keeping the agent's own cell unknown
prevented hidden target recovery without adding epistemic rigor.

**Consequences:**
Hidden target movement remains hidden until observed. Once the old target
location is physically reached, the current Now can disconfirm that location and
begin deterministic reacquisition.

### D-044 - Model output remains proposal-only before validation

**Status:** Accepted

### D-050 - Regime-B budget enforcement uses final prompt accounting
**Date:** 2026-08-27
**Status:** Accepted

**Decision:**
For G2.3.2, enforce Regime-B fixed-token budgets against the final
system-plus-user prompt before any model call. Use one deterministic canonical
estimator and a conservative safety multiplier for N, C, and R prompt
construction. Preserve Regime A, model settings, prompt templates, benchmark
questions, scoring, validator behavior, and the symbolic reference condition.

**Reason:**
The G2.3.1 fixed-budget fairness failure came from enforcing budget on an
incomplete representation prompt and auditing with provider token counts only
after dispatch. A pre-dispatch final-prompt budget gate repairs the fairness
invariant without tuning the architecture or benchmark to improve results.

**Consequences:**
The corrected `qwen3:0.6b` Regime-B rerun completed all `250` frozen paired
trials with `0` N wins, `0` C wins, and `250` ties for both proposal and
validated scoring. The fairness audit checked `250` N/C pairs with `0`
failures, and all `6` G2.3 invariants passed. The frozen Regime-A evidence
remains C `8`, N `0`, tied `242`, and should still be reported as an
ultra-small-model result where chronology was easier in a narrow group of H50
action-choice cases.

### D-051 - G2.3.3 OpenRouter replication is exact-free and resumable
**Date:** 2026-08-27
**Status:** Accepted

**Decision:**
Add an OpenRouter backend and G2.3.3 runner only as an external replication
layer. Use exact current `:free` OpenRouter model IDs with verified input price

### D-052 - G2.3.3 smoke allows prompt-only JSON compatibility but requires schema-valid rows
**Date:** 2026-08-28
**Status:** Accepted

**Decision:**
For exact `$0/$0` OpenRouter models that do not advertise native
`response_format`, G2.3.3 may attempt a prompt-only JSON smoke path. The

### D-053 - G2.3.4 relaxes only OpenRouter provider data collection for synthetic prompts
**Date:** 2026-08-28
**Status:** Accepted

artifacts and frozen G2.3.2 benchmark controls while changing only provider
