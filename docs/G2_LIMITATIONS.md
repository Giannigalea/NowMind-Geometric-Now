# G2 Limitations

G2 is still a small symbolic research prototype.

It does not implement:

- full trajectory or path planning;
- geometric action transformations;
- G2.1 possibility geometry;
- L3 Veto Gate;
- identity;
- dreaming;
- LLM or OpenAI API integration;
- external model APIs;
- camera or microphone input;
- autonomous tool use;
- self-modification;
- quantum mechanisms.

The benchmark is synthetic and symbolic. Passing it demonstrates that the tested
source-separation policies hold under the generated scenarios. It is not
evidence of consciousness and is not a comparison against state-of-the-art LLM
agents.

The current memory model uses compact propositions and deterministic cue
retrieval. It does not model rich episodic structure, language, fuzzy semantic
retrieval, or learned embeddings.

The browser demo is an inspection surface, not a cognitive UI.
