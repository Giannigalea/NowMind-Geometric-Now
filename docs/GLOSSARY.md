# Glossary

## Now
The active computational/cognitive state for one processing cycle.

## `NowState`
Immutable software representation of one Now.

## Present Geometry
The structured relational representation available in the current Now.

## WorldState
Persistent ground-truth state of the simulated environment. It is external to the cognitive architecture.

## Observation
Current-cycle information emitted by perception from WorldState.

## Entity
A node/object represented in the Present Geometry.

## Relation
A typed relationship between entities.

Examples:
- left_of
- right_of
- above
- below
- inside
- contains
- on
- under
- near
- touching

## Observed relation
A relation directly generated from current-cycle observation/perception.

## Inferred relation
A relation derived by deterministic rules from observed/current relations.

## Provenance
Metadata describing where a piece of information came from.

## Confidence
A numeric estimate (0.0 to 1.0) attached to observations and inferences.

## Memory trace
Future G2+ stored information resulting from an earlier event. It is not the earlier Now itself.

## Memory reconstruction
Future G2+ current representation reconstructed from one or more stored traces.

## Hypothetical state
Future G2+ candidate state representing a possibility, not an observation.

## Continuity stitching
Future G2+ process by which successive present states are related into a useful narrative/model of temporal continuity.

## Identity anchor / identity constraint
Future G3+ relatively stable constraint used in constructing current identity. It is not equivalent to the entire identity or autobiographical memory.

## L1 Substrate
Raw environmental/perceptual substrate feeding the current cycle.

## L1.5 Present Geometry
Explicit geometric/relational state constructed from current observations.

## L2 Conscious Core
Functional name for current-cycle reasoning/evaluation. The name is architectural and does not assert phenomenal consciousness.

## L3 Veto Gate
Future safety/action-inhibition layer that can prevent candidate actions.

## Waterfall perspective
PCT metaphor describing the primacy of the currently active present while successive states continue to arise.

## Geometric reasoning
Reasoning over structured relations, constraints, distances, orientations, topology, or transformations rather than relying only on prose-token continuation.

## Latent geometry
Geometry of internal neural representations. This is not automatically the same as NowMind's explicit Present Geometry.
